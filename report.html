第 1 題：Fortran 程式與編譯執行

輸出一個能做 1 加到 N 的 Fortran 程式並完成編譯，確認可以成功執行計算並輸出結果。

作答過程

先檢查環境，發現沒有 gfortran；嘗試用 apt 安裝，但沙盒沒有網路而失敗。因此只完成程式碼，並指引使用者在自己的電腦或線上編譯器編譯；使用者回報已完成編譯並成功執行。

答案

program sum_n
    implicit none
    integer, parameter :: i8 = selected_int_kind(18)
    integer(i8) :: n, i, total
    integer :: ios
    write (*, '(A)', advance='no') '請輸入 N (正整數): '
    read (*, *, iostat=ios) n
    if (ios /= 0 .or. n < 1) then
        write (*, '(A)') '輸入錯誤：N 必須是正整數。'
        stop 1
    end if
    total = 0_i8
    do i = 1_i8, n
        total = total + i
    end do
    write (*, '(A,I0,A,I0)') '1 + 2 + ... + ', n, ' = ', total
    write (*, '(A,I0)') '公式驗證 N(N+1)/2 = ', n * (n + 1_i8) / 2_i8
end program sum_n
gfortran -O2 -o sum_n sum_n.f90
echo 100 | ./sum_n
